# Arco.IA

Ferramenta para criar vídeos para **Shopee Vídeo**.

## Versão Online (celular)

Funciona no navegador do celular sem instalar nada.

### Como colocar online (passo a passo simples)

1. Crie uma conta no **GitHub** (gratis): https://github.com/signup
2. Crie um repositório novo chamado `arco-ia`
3. Faça upload de todos os arquivos desta pasta
4. Entre em: https://share.streamlit.io
5. Faça login com a mesma conta do GitHub
6. Clique em **New app**
7. Escolha o repositório `arco-ia`
8. Em Main file path coloque: `app.py`
9. Clique em **Deploy**

Pronto. Você recebe um link que funciona no celular.

## O que o app faz

- Gera prompts otimizados (UGC, POV, Lifestyle, Produto na mão, Close-up, etc.)
- Gera legenda pronta para Shopee
- Tem espaço preparado para Motion Control do Kling
- Instruções de como usar no Google Flow
